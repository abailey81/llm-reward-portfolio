So one line's marker condemned every other line's identically-named candidate — **unsubmitted,
unjudged, and ledgered permanent.**

Selection was `max(val_fitness)` with **no execution-quality condition**. `train_safe_default_count`
records steps where the authored reward RAISED and the R66 fallback stood in — archived, reported,
gating nothing. A candidate whose reward ran on half its steps could be frozen, and the sealed leg
would re-train it. **That is an identification hole**: H2 requires arms to differ ONLY in the
authored reward.

- **Measured over 613 records**: 594 clean, 16 trace (<1 %), **3 SEVERE** (53.66 %, 50.02 %, 39.40 %)

- **Effect-blind by construction** — it reads an execution counter, never a performance field; a test
  asserts this by inspecting the function's source
- **Threshold-INSENSITIVE**: worst trace 0.41 %, mildest severe 39.40 % — a **96× empty gap**, so any
  value in ~1–35 % partitions the data identically
- **PRE-DATA on the ADR-059 test**: RUN 1 discarded wholesale, RUN 2 held ZERO records, the sealed leg
  untouched, and **no arm contrast had ever been computed**
