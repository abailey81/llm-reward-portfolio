## 2. Campaign-hardening suite — the de-risking build (`docs/CAMPAIGN_HARDENING_PLAN.md`)
Driven by a **5-subsystem read-only scout** (orchestration/resume · LLM-cache · verify/freeze/monitor · storage ·
parallelization), which produced a **15-item risk register** and these findings: the engine is already strongly
built (atomic writes, idempotent resume, frozen-winner-load-not-re-search, freeze-hash enforcement, full
determinism pinning, an anomaly monitor); **disk is a non-issue (~50–200 MB; models/buffers never persisted)**;
**n_gpu=4 is a hard 6 GB wall** (measured OOM, refused at `run_campaign.py:1547`); `torch.compile` is **unwired**;
`cudnn.benchmark` is a **non-lever** for MLP SAC (no convolutions) so full determinism is ~free.

Built + tested (each result-neutral, test-then-commit; **32+ hardening tests green, ruff clean**):
- **#1 Search-replay cache** (`src/llm/loop.py`, wired into serial `run_arm`): on `--resume` the search replays
  archived candidates **and** sandbox-failures from disk — no Opus re-billing, byte-faithful (same winner). Caught
  a real reproducibility bug: un-archived failures would re-generate against non-deterministic Opus and silently
  change the candidate set → closed via a `{run_prefix}-{arm}.failures.jsonl` ledger. +3 tests.
- **#2 Graceful API-degradation** (`loop.py`): an LLM-call failure logs+skips the candidate (not cached → resume
  re-attempts) instead of crashing the arm. +1 test.
- **#3 Pre-flight gauntlet** (`scripts/preflight.py`): GO/NO-GO on disk/RAM/VRAM/API-key/freeze/data before the
  run. +8 tests. (User corrected the freeze-hash fn to `canonical_hash`.)
- **#4 Auto-guardian** (`src/utils/guardian.py`): hysteresis thermal governor (pause-and-cool, result-neutral) +
  RAM-throttle logic. **Wired into the SB3 training callback** (`monitoring.make_training_callback(governor=…)` +
  `trainer._make_governor`, config-gated `thermal_guardian`, default off). +7 tests.
- **#5 Auto-restart supervisor** (`scripts/supervisor.py`): relaunches `--resume` on crash with bounded
  exponential backoff; runs pre-flight first. +6 tests.
- **#6 Buffer-cap 2nd site** (`src/orchestration/parallel.py:277`): honors a spec `buffer_size` cap so the replay
  buffer doesn't scale with B\* (the silent OOM trap when B\* rises).
- **Parallelization verdict** banked: n_gpu=2 proven / 3 faster-but-creeps / 4 impossible; torch.compile + SBX are
  the only real result-neutral speed levers; most others change the frozen experiment.
- **Remaining completeness (deferred):** parallel-path search cache (`parallel.py::_drive_llm_arm`) — the headline

## 4. Model research & decision (the reward-designer LLM)
Deep current research (mid-2026) across frontier-closed, open-weights, and the reward-design/numeracy literature
(a transient classifier outage caused an agent fan-out cascade; the decision-critical, well-sourced findings still
came through). Two findings reshaped the framing:
- **Determinism is dead for hosted frontier APIs** — Opus 4.8 removed `temperature`/`top_p`/`seed`; the cause is
  batch-invariance under dynamic server batching (Thinking Machines). → This **validates archive-replay** as the
  only reproducibility path, and means only a **self-hosted open model** gives true determinism.
- **The numeracy bottleneck** — LLMs cannot reliably verbalize/compare close small floats (50–70%; arXiv
  2602.07812 "LLMs Know More About Numbers Than They Can Say", NUMCoT 2406.02864). Our fed CVaR values
  (−0.0577 vs −0.0582) sit squarely in the failure regime → a **citable mechanism for the predicted null** + a
  scaling hypothesis.
- **Sonnet 5** (released 2026-06-30): near-Opus-4.8 capability at ~40% cost — belongs in the panel, not as sole
  primary (1-day-old = stability risk for a frozen, months-later-examined run).
- **Licenses verified clean:** Qwen3 = Apache-2.0, DeepSeek V4/R1 = MIT, Kimi K2 = Modified-MIT (all academic-OK).

**DECISION (see ADR-039):** primary confirmatory designer = **Claude Opus 4.8** (frontier → unassailable "even
the best is null"). The **model panel is REQUIRED (not optional)** for the world-class generality the priorities
demand: **strong diverse models only — NO weak models** (user dropped Haiku; weak-model nulls are uninformative
and invite dismissal): **Opus 4.8 + GPT-5.5 + Qwen3-Coder** (open, the reproducibility anchor) [+ optional Gemini
